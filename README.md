# School Hub

Build a simple and modern **School Management App V1**.

### User Roles

Create 3 login roles:

* Principal / Admin

* Teacher

* Parent

### Authentication

Create a clean login page with:

* School logo and name

* Email

* Password

* Login button

* Forgot password

After login, redirect users to their role-based dashboard.

### Principal Dashboard

Principal can:

* View total students and teachers

* Add / edit / delete students

* Add / edit / delete teachers

* Manage classes

* View attendance

* Create school notices

* Manage class timetable

### Teacher Dashboard

Teacher can:

* View assigned classes

* View students

* Mark attendance

* View timetable

* View school notices

### Parent Dashboard

Parent can:

* View their child's profile

* View attendance

* View timetable

* View school notices

### UI/UX

Create a clean, premium and professional school dashboard.

* Responsive for mobile, tablet and desktop

* Simple sidebar navigation

* Clean cards and tables

* Modern typography

* Soft rounded corners

* Minimal colors

* No oversized buttons or text

* Simple and easy-to-use interface

### V1 Only

Keep the first version simple.

Do not add fees, exams, AI, QR attendance, bus tracking or chat yet.

Use a proper database and role-based access so Principal, Teacher and Parent can only access features allowed for their role.
